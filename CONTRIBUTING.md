# Contributing

Thank you for helping improve Dog Measurement Guide.

## Development

1. Fork and clone the repository.
2. Use Node.js 22 or newer.
3. Follow the local setup in [README.md](README.md).
4. Keep credentials and deployment-specific values out of commits.
5. Run `npm test` from `worker/` before opening a pull request.

Keep changes focused and describe their user-visible effect. Add or update tests when changing validation, security controls, CSV generation, or Worker request handling.
